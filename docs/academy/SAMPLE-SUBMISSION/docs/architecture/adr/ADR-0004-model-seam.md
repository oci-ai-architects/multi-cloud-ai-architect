# ADR-0004: Task contract above the seam, provider adapters below, gateway in between

Status: accepted 2026-09-30 · Decision: model · Owner: platform engineer

## Context

Two model tasks exist: `extract_invoice` (PDF text to schema) and `explain_flag` (one paragraph for
the clerk). Provider catalogues and prices kept moving through 2026. The firm wants to avoid a
rewrite when it changes provider, and wants a fallback if the primary is slow or down.

## Options considered

1. **Call the provider SDK where it is needed.** Fastest to write. Rejected: the support-triage
   worked example in the AI Architect plugin shows the cost, three call sites and nobody owning
   the fallback.
2. **Lowest-common-denominator wrapper** (one `chat()` function). Rejected: structured output and
   PDF handling differ by provider, and a generic wrapper hides the very capability extraction
   depends on.
3. **Task contract plus adapters**: product code calls `extract_invoice(text)` and
   `explain_flag(evidence)`. Adapters for provider A (Google, Gemini API) and provider B
   (Anthropic, Claude API) map each task to a model, structured-output mode, timeout and retry.
   Both route through Cloudflare AI Gateway for logging, caching, rate limits and fallback.

## Decision

Option 3. Provider A is primary for cost; provider B is the fallback. Model ids and prices are
pinned in `cost-model.json` with retrieval dates, never typed in code.

## Consequences

- Accepted cost: two adapters to keep current, and a contract test per adapter in CI.
- The gateway becomes a dependency on the hot path; if it fails, the worker retries direct to the
  provider with the same adapter (tested once, fixture).
- Quality differs by provider and the product must tolerate it: the second-provider slice shows
  date-format drift on provider B, handled by the schema validator with the prompt unchanged.

## What would reverse this

If one provider wins on both cost and accuracy for six consecutive weekly samples, drop the second
adapter to a fake adapter for contract tests only, and keep the seam.

## Acceptance eval

`gold-01`, `gold-02`, `gold-03`, `ref-02` run on both adapters without a code change above the seam
(`06-evals/run-report.md`, second provider slice).
