# Leadership benchmarks: the work an AI Architects brand has to beat

Researched 2026-10-05 from live sources (web search, page fetches, GitHub API). Every row cites a source.
Claims that rest only on third-party reviews, conflict between sources, or could not be confirmed on a
primary page are marked [UNVERIFIED]. No employer-confidential or customer material is used.

How to read each row: **Best at**, what it does better than anyone else. **Gap**, the weakness we can
exploit. **Bar**, the minimum our equivalent must clear to be taken seriously.

## Positioning wedge: three things no benchmark above owns

**1. Architecture-as-a-runnable-kit, across clouds.**
The cloud centres (AWS, Google, Azure) are each locked to their own vendor. The SDD tools (Spec Kit,
OpenSpec, BMAD, Kiro) start at the feature and skip architecture. C4 and arc42 have no agent
vocabulary. We own the **agentic reference architecture that ships as a repo**: a spec (Spec Kit and
OpenSpec compatible), an ADR set, a C4 agentic profile and arc42 addendum, AGENTS.md and SKILL.md
files, an eval suite, and deployable variants on at least two clouds. Proof point to publish first: one
PRD-to-portal reference taken end to end on AWS and GCP, scored against the AWS Agentic AI Lens.

**2. The eval-gated ADLC: "spec-anchored, eval-accepted".**
Böckeler names the SDD failures: verbose specs, non-determinism, over-specification. The Radar puts
instruction bloat and swarms in Caution. Anthropic and Maven teach evals separately from architecture.
No source read links them. We define the lifecycle where **every spec and every ADR has an acceptance eval**,
specs are sized to the change, and determinism is measured. Publish it as a short "Method" page in the
Linear format, back it with an open eval harness, and measure review time against Spec Kit.

**3. A vendor-neutral AI Architect credential assessed on design work.**
Vendor exams each cover one platform and retire on the vendor's schedule (Microsoft lists AI-102 as
retired 2026-06-30; Claude CCA-F launched for partner-network members). The Maven cohorts checked
($999–$4,200) issue completion certificates. The
academy we build certifies by **graded design review**: the candidate takes a PRD to a solution design,
specs, evals and deployment, and is reviewed against a published rubric. Price it between the
$25–30/mo platforms and the $2.4k–4.2k cohorts, with a free tier at least as good as Kaggle's intensive.

**Do not try to own:** protocols (MCP and A2A belong to AAIF), model-provider guidance
(Anthropic/OpenAI), or a generic agent-framework course (Maven is saturated).

**Open checks before any of this goes public:** confirm the [UNVERIFIED] pricing on vendor pages
(Kiro, DeepLearning.AI, Skill Builder, CCA-F); settle A2A's version and dates from a2a-protocol.org;
check whether Thoughtworks Radar Vol. 35 (expected late 2026) has been published.
