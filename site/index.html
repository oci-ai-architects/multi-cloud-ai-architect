The method

What the method builds on, and what it adds

Three sources the method relies on, what each one covers, and the rule the method adds. Each was read on 5 October 2026.

  • Each cloud's lens is written for that cloud

    The AWS Agentic AI Lens, published in June 2026, says it is “built around the AWS services and open source frameworks” for agentic AI. The method uses its questions as a review checklist and asks the same design to run on a second platform.

    Source: AWS Agentic AI Lens

  • Spec tools can oversize the spec

    Birgitta Böckeler's October 2025 review of Kiro, Spec Kit and Tessl found one tool turning a small bug into four user stories and sixteen acceptance criteria. Her review does not cover decision records or evals. The method sizes the spec to the change and keeps it readable by Spec Kit and OpenSpec.

    Sources: Böckeler on SDD tools, Spec Kit, OpenSpec

  • Evals already run in CI

    Anthropic's January 2026 guide to agent evals recommends running them in CI on every agent change. The method adds one rule on top: an architecture decision record counts as accepted only when its named eval passes.

    Source: Anthropic on agent evals

The kit

Skills in the open SKILL.md format, written once and installed into Claude Code, Codex, Cursor or Cline through thin adapters. Anything specific to one provider lives in that provider's pack, so the core stays neutral.

  • Usable todayNothing to install yet. The method and the provider comparison on this site are the parts you can use now.
  • In progressA repository layout being reshaped from an OCI-first repository. Drafts of the method skill and of six provider packs (AWS, Azure, Google Cloud, Cloudflare, Vercel, Railway) exist. None has passed review.
  • Not yetPublic repositories, releases and eval results. Each repository opens under Apache-2.0 after the organisation is renamed and the repository passes review. The names on the right are the target layout.
  • architect-skills

    The neutral core: RAG, MCP architecture, agent orchestration, AI security, FinOps, diagramming and Terraform.

  • pack-<provider>

    One pack per platform: AWS, Azure, Google Cloud, Cloudflare, Vercel, Railway and OCI. Provider names are used only to say what the pack is for.

  • patterns

    Solution patterns, each with a business view, a technical view and an agent spec.

  • stacks-<provider>

    Deployable stacks, one folder per stack, released as versioned archives.

  • example-<use-case>

    Worked examples taken end to end, with provider adapters inside.

The credential is a reviewed design

Each vendor exam covers that vendor's platform, and exams retire on the vendor's schedule: Microsoft lists AI-102, the Azure AI Engineer Associate exam, as retired on 30 June 2026. The academy will assess one design taken from brief to two deployments.

Not open yet. The rubric will be published with a sample assessed design before assessment opens. The price is not set.
