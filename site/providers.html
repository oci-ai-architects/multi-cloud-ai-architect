What the table says

Every platform now ships skills and MCP

All seven publish a skills repository and at least one MCP server from their own GitHub organisations. Google Cloud, Microsoft, Vercel and Railway also run hosted MCP endpoints, which changes the security review: the server is no longer a process you run, it is a service you grant access to.

Certification is where the platforms diverge most

AWS, Google Cloud, Microsoft and Oracle each certify agent or generative AI skills on their own stack. Cloudflare has no developer-platform certification, Vercel has no individual proctored exam, and Railway has none at all. An architect who works across these platforms has no single credential that covers the work.

Architecture guidance is uneven

AWS, Google Cloud and Azure publish architecture centres with agentic guides. Cloudflare publishes reference architectures. Vercel and Railway publish agent guides and agent-readable docs, without a well-architected framework. The method on this site is written to sit across all of them.
